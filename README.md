# 电子量角器（iOS 微信小程序）

基于微信小程序原生能力打造的拟物电子量角器，针对 iPhone 调优：Taptic Engine 触觉反馈、高刷新率顺滑旋转、Retina 矢量渲染。支持基准线设定、相对转角测量、度/弧度切换、齿轮音效、磁吸归零、1000 条本地记录与 CSV 导出。

## 目录结构

```
e-protractor/
├── app.js / app.json / app.wxss      # 全局配置、深色主题、tabBar、隐私合规

├── pages/

├── components/
│   └── protractor-dial/              # Canvas 2D 拟物仪表盘组件
├── utils/

└── assets/audio/                     # tick.wav（齿轮咔哒）/ snap.wav（磁吸闭锁）
```

## 运行方式

1. 用**微信开发者工具**打开本目录（`E:\code\e-protractor`）。
2. 把 `project.config.json` 里的 `"appid": "touristappid"` 替换成你自己的小程序 AppID（需为**非个人主体**且已认证，否则无法调用部分能力/过审）。
3. 真机预览 / 调试：iOS 设备扫描预览二维码。首次使用会在 iPhone 弹出「运动与健身」系统授权，需允许。
4. 编译运行即可在模拟器或真机查看。

> 音频资源已生成（`assets/audio/*.wav`）。若需替换音效，把等长的短 WAV 放到同目录即可。

## 与原方案相比的关键修正（已落地）

| 项目 | 原方案 | 本实现 |
| --- | --- | --- |
| 角度归一化 | `((delta+180)%360)-180`，JS 负数取模会算错（如 -200° 得 -200） | `normalizeAngle()` 先折叠到 [0,360) 再映射到 [-180,180)，结果正确 |
| 采样频率 | `interval:'ui'`（实际约 16Hz） | `interval:'game'`（约 50Hz），量角器更跟手 |
| 矢量渲染 | `<svg>` 标签（小程序 WXML 不支持原生渲染） | **Canvas 2D** 绘制，真机/审核环境稳定出图 |
| 显示符号 | 未处理 `-0.0°` | `Object.is(n,-0)` 归一，避免 `-0.0` 异常 |
| 自动锁定 | 未实现 | 增加 Auto-Hold：连续 1s 变化 <0.1° 自动锁定并高亮 |

## 已知限制（产品/技术层面）

- **最佳场景为「平放旋转」**：算法以 DeviceMotion 的 `alpha`（绕 Z 轴方向）为基准，适合手机平放/贴近平面绕垂直轴转动。若手机立握像转方向盘，应改用 `gamma`（绕 Y 轴），后续可加模式切换。
- **`alpha` 受磁场干扰**：依赖罗盘方向，强磁环境静态精度会下降；已通过「设基准」一键扣除静态偏差缓解。
- **非平面倾斜**：绕 X/Y 轴俯仰/翻滚会引入投影误差，已加 `>15°` 倾斜警告与提示贴紧测量面。
- **iOS 专属**：`vibrateShort({type})` 的 heavy/medium/light 分级在 iOS 生效；Android 仅支持部分档位（本程序以 iOS 上线为目标）。

## 上线与审核清单

1. **隐私协议**：登录 MP 后台 → 设置 → 服务内容/隐私协议，填写并发布隐私政策；代码中已通过 `wx.requirePrivacyAuthorize` 在首次进入弹窗授权（`__usePrivacyCheck__: true`）。
2. **类目选择**：工具 > 实用工具 / 效率，避免选错类目被拒。
3. **权限说明**：`scope.userLocation` 已声明 `desc`；本程序核心能力为本地传感器，**不强制联网、不上传数据**，审核更易过。
4. **功能自测**：iOS/Android 各真机、不同尺寸、弱网下验证；重点测「设基准→旋转→磁吸→记录→导出」。
5. **侵权/合规**：名称、图标、文案避免与系统「测距仪/水平仪」混淆引发商标风险。
